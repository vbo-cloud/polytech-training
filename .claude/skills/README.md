# Skills du projet

Dossier réservé aux skills spécifiques à ce projet (utilisées par Claude Code selon le workflow décrit dans `CLAUDE.md`, et par Claude Cowork pour signaler les écarts de convention).

- `dotnet-conventions/` — conventions C#/.NET (EF Core, logging, config, résilience)
- `docker-conventions/` — conventions Dockerfile/docker-compose
- `azure-pipelines-conventions/` — conventions pipeline Azure DevOps (YAML)
- `terraform-conventions/` — conventions Terraform (nommage Azure, tags, lifecycle, sécurité/coût) — adapté depuis `job-finder`

À compléter si le périmètre s'étend (Python/Flask, Node.js/Express — volontairement non couverts pour l'instant, hors scope du week-end).
